# 声搭 · MicPatch

[English](README.en.md)

## v0.1.1：多音源与自动恢复

最多混合 16 路音源：麦克风、本地文件和播放设备，可任意组合。每路有独立增益、静音和电平，每个文件可独立播放、暂停和循环。

「播放设备」音源会采集选中设备正在播放的**全部声音**。不要采集通话软件播放对方声音的设备，否则可能把对方的声音送回去。应用禁止采集与混音输出完全相同的播放端点，但不会自动消除跨设备回声。

默认自动保存音源及参数，并在下次启动恢复；可在设置中关闭。不会恢复发声、文件播放或播放进度。找不到设备时保留设置，不会改用系统默认设备。

## 设置

- **语言：** 默认简体中文，可切换 English。系统设备名、文件名和 Windows 对话框的系统文字保持原样。
- **主题：** 石墨深色、海蓝深色、浅色。
- **总静音：** 全局热键可用 `Ctrl+Alt+M`、`Ctrl+Alt+Shift+M` 或关闭，也可设置应用启动时默认总静音。
- **记住输出：** 新安装默认开启，升级保留原来的开关。只恢复同一个仍可用的设备，不会自动改选其他设备、启动发送或播放文件。

设置保存在当前 Windows 用户的 `HKCU\Software\MicPatch`。语言、主题和启动偏好在重新打开应用后生效。

Windows 11 x64 便携混音台。将多路声音混成通话软件可选的录音输入。应用只在用户确认后启动驱动安装，不更改系统默认设备，也不会自动回退到默认扬声器。

## 混音台界面

顶部显示发送状态，并提供开始、停止和总静音。路由区显示混音目标和实际总输出电平；左侧选择音源，右侧调整所选音源的增益、静音和效果。总静音时仍可观察各路电平，便于在不发送声音时调音。设备下拉和文件选择沿用 Windows 控件。

## 专用虚拟麦克风（开发验证）

在混音台路由区打开「虚拟麦克风」，可检查专用设备是否存在、驱动是否启动，以及是否发布供数接口和录音端点；检查不占用音频写入接口。没有正式发布驱动包的开发版只显示检测结果，不请求管理员权限。正式版随应用提供受 Windows 信任的签名包时，停止发送后可从该入口确认安装，再通过一次 UAC 完成。安装不会更改默认输入、启动签名策略或自动重启。

安装并加载通过签名策略的 [MicPatch 驱动](driver/README.md)后，刷新设备、选择「麦克风（声搭） · 直接输出」并启动。通话软件的输入选择带 **MicPatch** 的虚拟麦克风，输出仍选实体耳机。该路径不使用 VB-Audio，也不需要额外的虚拟播放端。驱动未安装或接口未启用时，应用不会列出此目标。

**当前已验证用户态构建和下面的 VB-Audio 路线，未验证专用驱动的 WDK 构建、加载或实机录音。**

## 使用已验证的 VB-Audio 路线

1. 确认 Windows 中已有虚拟音频线，并且它的播放端和录音端都已启用。**本机已实测的配对是：应用输出选 `CABLE Input (VB-Audio Virtual Cable)`，通话软件输入选 `Virtual Mic (VB-Audio Virtual Cable)`。** 其他机器上的标准 VB-CABLE 录音端通常叫 `CABLE Output`。通话软件的输出仍选实体耳机。
2. 启动 `MicPatch.exe`。从「添加音源」加入实体麦克风和/或本地文件，再明确选择播放输出。测试时不要把通话软件播放端设为虚拟音频线，也不要把该线的录音端当作本程序的麦克风源。
3. 点击启动。要发送文件音频，使用播放按钮；可随时暂停或切换循环。各路增益、静音和电平分别控制，总静音会静音整条输出；总电平显示实际送出的音量。音量百分比是线性增益，100% 为原始电平。总线有峰值保护，但过高增益仍可能让声音产生明显失真。
4. 更换设备或文件前先停止。设备断开后不会切换到其他设备；重新接好，再刷新列表并启动。若麦克风启动失败，检查 Windows 的麦克风隐私设置是否允许桌面应用访问。

本地文件使用 Windows Media Foundation 解码，主要面向 WAV、MP3；AAC/M4A 取决于系统编解码器。通话应用的降噪和自动增益有时会压低音乐或音效，请用真实通话确认对方听到的效果。

### 通话辅助

- **总静音热键 `Ctrl+Alt+M`**：应用打开时，即使窗口不在前台也可切换。总静音只关闭发送，不暂停文件。底栏显示 `1409` 时，组合键已被注册，Windows 不提供占用者；可先关闭可能使用此热键的应用，重开 MicPatch，或用窗口里的总静音控件。其他注册错误显示实际错误码。
- **自动压低伴奏**：需同时添加麦克风和文件，默认关闭。麦克风达到触发电平时，文件音量平滑降低约 12 dB；安静或麦克风静音后平滑恢复。它按麦克风电平触发，较响的背景声也能触发。
- **人声清晰 EQ**：默认关闭。开启后只对麦克风削减低频轰鸣、轻微提升清晰度，不处理文件音源。

目前未提供指定应用回环、变声、多个命名场景或正式签名安装包。

## 构建和测试

需要 Visual Studio 2022（含 MSVC x64 和 Windows SDK）及 CMake 3.25+。从项目目录执行：

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

### 发布时配置一键安装

使用 `-DMICPATCH_RELEASE_DRIVER_DIR=<正式签名包目录>` 配置 CMake。目录必须包含签名后的 `MicPatchMic.inf`、`MicPatchMic.cat`、`MicPatchMic.sys`。构建会把文件复制到应用旁的 `driver-package`，并将三份文件的 SHA-256 固定到 `MicPatchDriverInstall.exe`。正式部署应将应用、助手和包放在管理员控制的 `Program Files\MicPatch` 下，不能从用户可写目录提权，也不能用未签名的开发包代替正式包。Windows 仍会验证驱动包信任与适用性；有签名文件并不等于安装或加载已经验证。

可执行文件位于 `build/Release/MicPatch.exe`。使用静态 MSVC 运行库，不需要安装第三方音频框架。Windows 音频组件、Media Foundation 和虚拟音频线仍需由系统提供。
